# Blind playtests (November 2026, sixth round)

## Method

Same as `playtest-2026-11-04.md`: each run was a fresh agent with only the
Playwright browser tools, no repo and no docs, given a persona, tasks and a
fixed report format, one after another in one browser. Run 1 started from a
cleared install. Runs 2–5 used the demo data, loaded on a cleared install
(through a throwaway prediction, since a cleared install sends every full page
load to the Warm-up), each keeping what the run before left. Screenshots are
in `.playwright-mcp/playtest-2026-11-05/` (gitignored). No run signed in,
bought anything, erased data or left localhost.

Stand-ins: Reduce Motion through `prefers-reduced-motion` (runs 1–2); low
vision through 150% CSS zoom (run 4); red-green colour blindness through a
deuteranopia colour matrix over the page (run 5), whose screenshots show
roughly what he sees.

**Fixes to the draw:** "clearing a backlog" on a fresh install had nothing to
clear, so that run used the demo data; a 28-year-old "retired civil engineer"
became a working one; run 5 came out nearly the same person as run 4 (26,
non-binary, low vision), so its age, gender and access need were drawn again.

**What landed.** Reduce Motion was respected throughout: no slide, bounce or
fade was seen or measured (runs 1–2). The chart passed under deuteranopia:
over (orange) and under (blue) stay apart, and position, region words, the
title and the counts table carry the same meaning without colour (run 5). The
same-day rule was explained before the answer was spent ("That's a fair game",
run 1). Finance being off was said plainly in five places, the Log line at the
moment of choosing among them (run 2). The confidence lock, the 24-hour window
with its clock time, and the refusal to change old answers all held and said
why (run 3). The card's give-or-take, its count and "N categories not shown"
made it credible to a skeptic, and hiding a category never changed the rating
(runs 2, 3, 5). Practice was clearly kept out of the streak, the score and the
card ("it won't let me cheat past them with trivia. Shame, but fair", run 4).
No console errors from app code.

## Decisions for the owner

| Finding | Runs | Note |
|---|---|---|
| **An open prediction's title can be rewritten to its opposite.** "The Fed holds rates" at 70% became "The Fed does NOT hold rates" at 70%, the same as moving to 30%, with no warning or history, including on the due day once the news is out | 3 | The open title-edit hole, now shown plainly. Recommended before: a title edit counts as a new prediction logged now (so it's unscored that day). Alternatives: lock the title after a grace period (as for an answer), or keep an edit history on the row |

## Web only, not fixed

- Export says "Exporting isn't available on this device" on web.
- The practice-reminder offer under a finished practice needs notification
  permission, which web doesn't have (as last round).
- "Share as text" fails silently in the headless browser (`AbortError`); one
  run saw the screenshot hint appear only after returning from the paywall.
- A history filter stayed selected after leaving and coming back through the
  tabs (run 2); expected with tab state kept, noted in case it surprises.

## Test artefacts, not app faults

- Run 3 deleted two demo predictions and added one, so runs 4–5 saw 147
  answered rather than 148.
- "Your 4 months on file" on the Plus card counts whole months from the seed's
  first answer.
