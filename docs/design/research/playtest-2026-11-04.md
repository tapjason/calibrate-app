# Blind playtests (November 2026, third round)

## Method

Same as the 2026-11-03 round (`playtest-2026-11-03.md`): each run was a fresh
agent with only the Playwright browser tools, no repo and no docs, given a
persona, tasks and a fixed report format, one after another in one browser.
Run 1 started from a freshly cleared install; run 2 loaded the demo data on top
of run 1's three predictions, and runs 3 to 5 kept what earlier runs left.
Screenshots are in `.playwright-mcp/playtest-2026-11-04/` (gitignored). No run
signed in, bought anything or erased data. Run 2 opened one of its own
screenshots; no other file was read. Run 4 also read the browser's network log.

| # | Persona | Start | Screen | Verdict | Ease |
|---|---|---|---|---|---|
| 1 | Jordan, 22, student, predicts NBA games and politics, wants to beat friends | Fresh install | 375 × 667, light | **Unsure**: "my Lakers call didn't count because I answered it tonight" | 4/5 |
| 2 | Ana, 38, nurse, English a second language, reads literally, night shifts | Demo data | 390 × 844, dark | **Keep**: counts, not judgements | 3.5/5 |
| 3 | Marcus, 29, runs a running club, wants to show off and bring friends in | Run 2's data | 390 × 844, light | **Depends**: would post the card, not the recaps | 3/5 |
| 4 | Elena, 52, data-protection lawyer, checks what leaves the phone | Run 3's data | 375 × 812, light | **Only for harmless things** | 4/5 |
| 5 | Kai, 26, competitive, wants a better badge tonight by any means | Run 4's data | 390 × 844, light | **Gamed it**: Social to Forecaster and Finance to Tracker in ten minutes | n/a |

**What landed.** Every lean shown with its counts ("Of 57 things you called
80–100% likely, 38 happened") read as fact, not verdict (run 2). The share
card's give-or-take and "2 categories not shown" (D42) read as honest, not as
bragging (run 3: "Give or take 4 is the best part. It makes the 87 look
earned"). The week card's "Across all 148 answers, …" line separated the week
from the whole record (runs 2 and 3). The Coach text in You was the one
privacy text run 4 would sign off on as written, and nothing typed (title,
reflection) appeared in any network request. Same-day answers stayed
unscored in every way run 5 tried. No console errors from app code.

## Fixed the same day (step 151)

| Finding | Run | Fix |
|---|---|---|
| A date typed into "Pick a date" got past the field's minimum: today (answered at once, then "not scored"), or a year like 1906, shown as "Due Monday, Nov 5". Edit took a past date the same way | 1, 5 | The web field moves a date before its earliest day to that day, and the store holds the same floor on create and edit (`clampDueDate`, `src/engine/sameDay.ts`), so no path saves one |
| Resolve said an answer wasn't scored only after Yes or No | 1, 5 | Before the question, for a prediction logged today: "You logged this today, so an answer today isn't scored. It still keeps your streak, and from tomorrow it counts." |
| The week card said "you ran well calibrated — 66% confident on average, right 81% of the time" | 2, 3, 4, 5 | "Well calibrated" only when the averages are within 5 points. Otherwise the whole window's lean when it has one ("you ran underconfident — …"), or "no clear lean — … On 25 answers, luck often moves it that far." |
| The recaps ignored the categories left off the card: their counts, "Tracker in finance: 3 to go", and with titles on, a hidden category's title | 3 | Both recaps follow the card's choice (`cardHiddenCategories`): the chips, the next-badge line and the titles leave them off, and the card says "N categories not shown" |
| "at its low end" appeared on some badge hints and not others, and was never defined | 2, 5 | Said every time a score is asked for ("a score above 85 at its low end"), and How scoring works says what it means: the score minus its give-or-take ("a score of 89, give or take 10, is 79 at its low end") |
| "No change since last week, over 21 answers" read as "more than 21" | 2 | "from 21 answers", as Up and Down say |
| Badge taglines: "over 20+ predictions" | 2 | "with 20 or more resolved" |
| On a signed-out install, RevenueCat is contacted at launch (a random per-install id, with locale and time zone), and nothing said so | 4 | The privacy policy's "If you don't sign in" and its RevenueCat row now say so; `APP_PRIVACY.md` records why. No change to the app |

## Decisions for the owner

| Finding | Runs | Note |
|---|---|---|
| **Rewriting an open prediction, then answering it early.** Edit any prediction logged on an earlier day, change the title to something already true ("Eat lunch today"), move it to the weak category, "Answer it now", Yes. It counts at the old confidence. Two of these took Social to Forecaster | 5 | The biggest hole left. Options: a title edit counts as a new prediction (logged now, so D41 applies); or titles can only be edited on the day they were logged (a typo window, like D34's 24 hours) |
| **Moving answered predictions between categories inside the 24 hours** donates answers to a weak category: three moves took Finance from 17 to 20 resolved (Tracker) | 5 | D34 allows it on purpose (misfiled answers). Options: allow the move only within the same hour, or only for open predictions |
| "Answering early is fine; just answer what you know now" invites answering things that haven't happened: two 20% No answers were near-free | 5 | Copy that only asks for answers already known ("Answer only if you already know how it turned out") |
| **Sports and news fit poorly.** The categories, starter ideas and placeholder are personal goals; "Add a category" is only in You; there's no "Tonight", and D41 now means tonight's game can't count | 1 | Options: "Add a category" on Log; a starter idea or two about the outside world. A same-evening prediction can't count under D41, which is the trade-off it made |
| Friends: run 1 looked for a leaderboard, run 3 for an invite link and a shared prediction | 1, 3 | D44 parks A9 and friend streaks for after v1, cooperative only. Run 3's first ask, a link in the text share, waits on `APP_STORE_ID` |
| **Deleting an answered prediction after 24 hours** isn't possible, only erasing everything | 4 | For sensitive entries (health, legal) a lawyer called it a right-to-erasure red flag. D34 locks the record so misses can't be hidden. Option: delete any time, with Insights counting what was deleted |
| Today's identity line names the *weakest* tier second, so earning Tracker in finance made the line look worse ("Forecaster in personal" became "Tracker in finance"); two runs read the second slot as a mistake | 2, 3, 5 | The contrast is by design ("Sharp in health · Tracker in money"). Options: name the second-best instead, or only show the contrast on the share card |
| The yearly recap's only badge line was the weakest category, with no rating and no best tier | 3 | Pick the best tier for the year card, the next badge for the week |
| Copy for a second-language reader: "you ran", "landed", "pad", "Tracker in finance: 3 to go", the Brier sentence's nested clause, "148 resolved" on Insights against "149 answered" in History | 2 | Joins the open copy points (the 70/85/90 ticks came up again) |
| Plus themes can't be previewed before the paywall | 3 | A preview, with the share button locked |
| The Story card's footer sits about 52–88 px from the bottom, where Instagram's reply bar goes (measured, not seen) | 3 | Check on a device |
| Usage stats on by default, silent when switched off; "Erase all data on this device" has no line saying what it covers; the sign-in screen has no privacy link | 4 | Small copy, ready to build once agreed |
