## Method

- **What changed from rounds 20–22.** At the owner's request ("make sure the criteria and
  combination factors differ slightly"):
  - **The combination: matched pairs.** Four pairs, each sharing a start state and a situation
    and differing mainly on one axis, so a split within a pair points at that axis (table
    below). The wildcard was drawn into pair C's second seat.
  - **The criteria: block B2 beside block B.** Block B stayed word for word, so the pairs, words
    and disappointment answer compare with earlier rounds. B2 added four measures:
    - sure before and managed after, per task (expectation against experience);
    - taps to the first thing worth having;
    - "do I believe it?" at the first thing said about the tester;
    - thinking and frustration at the end (two NASA-TLX items).
  - **Two new start states**, `first-week-school` and `first-week-retired`, so pair D met a week
    like their own (round 22 had an office runner's record on teenagers' phones).
- **Health check:** `web-playtester` passed every start state the cast needed, with no console
  errors from app code:
  - a fresh install through the Warm-up, the friend fold and a first log;
  - `threshold`'s unlock card naming the badge earned on the same answer;
  - hiding the words on `first-week-school`, with School as "Your own category", Health with an
    emoji keeping its word and default symbol, and every chip unticked leaving a card;
  - "Use another number" keeping typed words;
  - `first-week-retired`;
  - `return`'s run across a reload ("3 of 6", the summary whole);
  - `long-time`'s fold and card.
- **Between runs:** the browser closed (the MCP runs isolated, so each run began empty), the
  viewport, locale, time zone and a clock set through CDP before the page loaded, the stand-in
  set, the profile loaded on `/dev/seed`, then the history entry replaced with Today.
- **Stand-ins:**
  - page zoom 1.25 (run 1);
  - deuteranopia through CDP (run 2);
  - one-handed reach, by the tester's own care (run 5);
  - the accessibility tree and keyboard only (run 6);
  - CPU throttled 4× (run 7; again not felt: not verified);
  - `prefers-contrast: more` (run 8).

- **Focus and announcements:** focus falls to the top after an answer, Next, Got it or a closed
  sheet, and "Recorded" isn't announced (run 6). On the web `announceForAccessibility` does

  slider ignores arrow keys.

  heading is level 1 (React Native on iOS has no heading levels).

  local prices.
