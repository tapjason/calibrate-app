# Blind dry runs (October 2026)

## Method

Each run was a fresh agent with the Playwright browser tools only: no file reads,
no shell, no search. It got a persona, a goal and a fixed report format (walkthrough,
layout, copy, issues by severity, keep or delete). The runs went one after another,
since they share a browser. Screenshots are in `.playwright-mcp/dryrun/` (gitignored).

|---|---|---|---|---|
| 1 | 34, marketing, never heard of calibration, five minutes to decide | Fresh install | 375 × 667, light | **Delete, probably**: "the app told me to come back in a week" |
| 2 | 41, data analyst, knows Brier scores, judging rigour | Fresh install | 375 × 667, light | **Keep, tentatively**: the scoring page and min-N gates earn trust; the score itself can be gamed |
| 3 | 29, nurse, five months of data, evening check | Demo data | 390 × 844, light | **Keep**: the resolve run is quick and the streak pulls; the "Guesser" label grates |
| 4 | 52, impatient, small phone, dark mode | Fresh install | 320 × 568, dark | **Keep, just barely**: the button is always below the fold behind text |

Limits: agents can't feel haptics or see iOS sheets, they know what probability is
even when told not to, and two hit web-only issues (the share sheet can't open; the
first load in a dev build is slow). Their findings on confusion, copy and layout are
the useful part.

## What one of them found that holds up

- **Copy** (fixed, 121–122): "against the 47% you said" read as a misquote (it's
  the range's mean); "about 1.5" puzzled a non-numbers user while "about 2" for 2.45
  read as rounding down to an analyst, so near-halves now say "2 or 3"; a week
  card's "You ran underconfident" beside Today's all-time "overconfident at 80–100%"
  read as a contradiction, so Wrapped names its window; "80%100%" ran together on
  the chart at 320pt.
- **Rigour** (run 2): the score is calibration-only (no sharpness or Brier term), so
  logging safe or coin-flip calls can raise it; the band mean is unweighted; and the
  integrity bonus pays for a probability band, which is an improper incentive with a
  wrong rationale ("they tell you the most": near-50% calls carry the least
  information). **D23, D24.**
- **"Guesser"** (runs 1, 3): it means "fewer than 20 resolved here", but on Today and
  the card it reads as a verdict ("Guesser in finance" after five months). Tapping
  the identity line opens Share, not an explanation. **D27.**
- **Per-area numbers** (run 3): Insights shows badges per category but no score,
  even where a category has enough to show one. **D28.**
- **Category defaults to Work** (run 4), so an untouched gym prediction is filed
  under Work. **D29.**
- **Backup** (run 3): "Your predictions live only on this phone" after five months,
  with nothing more prominent than a row in You.
- **Notifications** (runs 3, 4): one switch for reminders, the digest and practice;
  practice times are fixed, which suits nobody on shifts.
- **Plus** (runs 2, 3): Coach reads as abstract; CSV export of your own data being
  paid drew objection; what they'd pay for (per-area trends, Brier and its
  decomposition) is half in Plus, half not offered.

## Not acted on

- Slider keyboard support, tap-to-seek landing at the middle: web only.
- The ~8 s first load: a development bundle.
- "Practice counts for nothing, so why do it" (run 1): the separation is deliberate
  (`CLAUDE.md`, Daily practice), and run 2 named the same line as good copy.
- The five-dot strip on the card has no legend: by design a mini visual
  (DESIGN_SYSTEM §7.5); one tester found it opaque. Worth watching.

## The Day-1 gap (run 1's severity 1)

Run 1 typed a prediction that said "by Friday" and chose "In a week", so the
Tomorrow preset didn't help them; the first real answer was a week out and every tab
was an empty state or a countdown. D18 made the first prediction due tomorrow by
default and added practice for the days between. What's still missing is a reason,
on Today, to think the first answer is close. **D30** proposes one: on Day 0 and Day
1, Today's progress block names the first answer's evening ("Your first answer:
tomorrow evening") above the 0-of-20 bar, so the nearest thing is first.
